# 网申执行手册

本手册按本工作区现行规则整理。事实源、浏览器路由和提交授权以 AGENTS.md 及三个正式 Skill 为准。

## 开始前

确认具体公司主体、岗位ID、批次、已选定的简历版本、投递额度和本次授权范围。读取当前网申档案和与岗位有关的经历边界。先保存官方完整JD，核对已有投递与历史材料。

浏览器采用用户授权通道；需要专用浏览器时使用非默认 profile，保留已有登录状态。登录、验证码、扫码与风险验证由用户处理。

## Batch Filling & Consolidated Verification

按模块准备已确认答案，填写基本信息、教育、实习、项目等完整结构化条目。相关控件有依赖时等待真实选项，再继续下一项。模块保存后读回，对照本次输入修正差异。

简历解析完成后逐项检查日期、机构、专业、职位、描述、责任范围和附件。PDF 中写了某项内容不代表表单对应字段已填写。保留原日期精度；需要更精确日期或未知高影响答案时交用户确认。

新增经历前检查是否已有同一条，避免重复。更换主简历后重新审计可能被解析覆盖的字段。公司提出的新问题按当前事实回答，不用旧申请答案代替未知事实。

## 保存与失败

页面显示、成功点击和字段变色都不能单独证明服务器已保存。通过页面读回、重新进入记录或明确保存结果确认。刷新前确认可恢复的状态。

单个控件按语义定位、组件特定方式、一次安全重入三层处理，仍失败则保留当前状态和未完成字段交接。不得循环盲点或猜测选择项。

## 提交边界

- review：完成审计后停在最终提交前。
- preauthorized：限用户已明确授权的岗位或批次，满足岗位、材料、额度与高影响答案核验条件后执行。
- autonomous：另需明确范围、筛选规则和提交授权。

出现验证码、额度冲突、未知高影响问题或不可逆弹窗时交用户处理。

## 完成后的证据与登记

提交成功必须有成功页、账号申请记录、确认邮件或用户明确确认。保存本次材料、字段审计、提交凭据和官方JD快照；然后按主表事务协议登记实际日期与申请日志并读回（OfferNotes 同步已停用）。

交付全字段提交内容清单，敏感信息打码，注明未填写项及原因、修正过的解析偏差。用户纠正的信息回到当前档案和相应工作流规则中。
